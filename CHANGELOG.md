# Changelog

## 1.0.4 — новый интерфейс и логотип

- Полностью новый экран: верхняя строка `AcidCode v… ●` с git-веткой, две панели
  с закруглёнными рамками, слева — файл/diff/результат инструмента, справа — диалог.
- Нижняя строка ввода в кислотно-зелёной рамке, справа модель, расход и лимит токенов.
- Живой предпросмотр: `read_file`, `write_file` и `edit_file` показывают файл или diff
  в левой панели, `run_shell`/`list_dir`/поиск — команду и результат.
- Кислотная палитра переведена на графит `#0b0b0b` и лайм `#b6f000`.
- Новый логотип `assets/acidcode-logo.svg`, обновлённый splash-экран.
- Версия `1.0.4`, обновлённый набор для друга.

## 0.9.0 — автообновление, темы, набор для друга

- Автообновление до старта TUI: `acidcode` читает `update_url`, ставит свежий
  архив и перезапускает процесс. `update_auto` теперь `true` по умолчанию
  (миграция конфига `config_version: 3`).
- `/update <папка|URL>` не только ставит, но и запоминает источник в `update_url`.
- Пять тем интерфейса: `acid`, `amber`, `ice`, `violet`, `mono`.
  `/theme` показывает список, `/theme amber` переключает, выбор хранится в конфиге.
- `theme.tcss` переведён на CSS-переменные `$acid-*`, палитры в `acidcode/themes.py`.
- `release.cmd` собирает ещё и `AcidCode-<версия>-friend.zip` — готовый набор
  для установки у друга: пакет, `install.bat`, `acidcode.cmd`, README, `SETUP.txt`.
- `acidcode.cmd` переведён на CRLF и UTF-8, `--version` без спецсимволов.

## 0.8.0 — обновления по каналу

- Модуль `acidcode/updates.py`: манифест `latest.json`, проверка версии,
  скачивание архива по HTTP или из папки, контроль sha256, безопасная распаковка.
- `/update` в TUI: установить обновление; `/update check` — только проверить.
- CLI: `acidcode update`, `acidcode update <папка|URL>`, `acidcode update check`,
  `acidcode --version`.
- Конфиг: `update_url` (папка или URL с `latest.json`), `update_check` (проверять
  при старте), `update_auto` (ставить без вопроса). По умолчанию проверка включена,
  автоустановка выключена.
- `release.cmd` и `make_release.py`: собирают `dist/acidcode-<версия>.zip`
  и `dist/latest.json` с sha256. Друг кладёт их в общую папку/на HTTP и обновляется
  одной командой.

## 0.7.0 — фильтры моделей, языки, планета

- Рейтинг моделей помечает каждую строку `[бесплатно]` / `[платно]`.
- Фильтры `/models free|paid|top|mid|bad` и русские синонимы
  (`бесплатно`, `платно`, `топ`, `среднее`, `кал`).
- Языки интерфейса: `/lang ru|en`, выбор хранится в `config.json` (`"lang"`).
  Переводятся баннер, placeholder, справка, рейтинг, расход, статус и Footer.
- Планета перерисована: ровный корпус из 19 колонок, 18 кадров, сдвиг континентов
  по широте, без разъезжающихся краёв.
- Планета гаснет только на первом токене ответа (рассуждения её не трогают)
  и держится минимум 0.35 с, чтобы не мигать.
- Обрывки неудачной попытки очищаются перед автопереключением модели.
- Пустой баланс ловится и по `quota`, не только по `credit`.

- Под каждым вопросом строка `◇ provider/model` — видно, кто именно отвечает.
- Системный промпт получает рантайм-строку: провайдер, модель, запрет называть себя ChatGPT/GPT-4/Claude.

## 0.6.0 — провайдеры OpenAI и Anthropic

- Добавлен провайдер `openai` (`api.openai.com/v1`), модели GPT-5.x.
- Добавлен провайдер `anthropic` через OpenAI-совместимый шлюз (`api.anthropic.com/v1`).

- `_friendly()` понимает `insufficient_quota`, `credit_balance_exhausted`, `credit balance is too low`.

## 0.5.0 — бюджет, рейтинг, заставка, планета

- Лимит 200 000 токенов на каждую модель, счётчики в `~/.acidcode/usage.json`.
- `model_budget` в конфиге, команда `/usage` и `/usage reset`.
- Рейтинг моделей `/models`: ТОП / СРЕДНЯК / КАЛ, полосы расхода, отметка ключа.
- Переключение `/switch <номер>` и `/switch next`.
- Автопереход на следующую модель при исчерпании бюджета.
- Автоповтор на `503`/`429`: пробует следующую модель, при неудаче возвращает исходную.
- Экран загрузки `WEXOV PRODUCTION`, 2.2 с или любая клавиша.
- ASCII-планета в чате во время ожидания, 8 кадров, гаснет на первом токене.
- Расход модели виден в шапке: `provider · model · 12.4k/200k`.
